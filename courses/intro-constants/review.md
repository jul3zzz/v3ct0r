# Relecture · Intro Constantes

- Archimède (*De la mesure du cercle*) : polygones inscrits et circonscrits à 96 côtés, d'où $3 + \frac{10}{71} < \pi < 3 + \frac{1}{7}$.
- Nombre d'or : $\varphi = \lim F_{n+1}/F_n = \frac{1 + \sqrt5}{2}$.
- « apparu avec les intérêts composés » : Jacques Bernoulli (1683) étudie $\lim (1 + 1/n)^n$ ; la notation $e$ vient d'Euler. Formulation prudente : « apparu », pas « inventé ».
- Identité d'Euler : cas $\theta = \pi$ de $e^{i\theta} = \cos\theta + i \sin\theta$. Elle relie $e$, $i$, $\pi$ (et $0$, $1$) ; le nombre d'or n'y figure pas, d'où « relie e, i et pi ».
- « Onze vues » : le module compte 11 vues dont 8 constantes ($\pi$, $\varphi$, $\sqrt2$, $e$, $i$, $\gamma$, $\zeta(3)$, $\ln 2$), plus comparaison, marche des décimales et identité d'Euler. Ne pas dire « onze constantes ».
