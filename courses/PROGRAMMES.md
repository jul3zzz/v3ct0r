## Première année

**MPSI, MP2I.** Semestre 1 : raisonnement et vocabulaire ensembliste ; compléments de calcul algébrique et de
trigonométrie ; nombres complexes ; techniques fondamentales de calcul différentiel et intégral (fonctions d'une
variable réelle, primitives et équations différentielles linéaires) ; nombres réels et suites numériques ;
fonctions d'une variable réelle : limites et continuité, dérivabilité, convexité ; arithmétique dans ℤ ;
structures algébriques usuelles ; calcul matriciel et systèmes linéaires ; polynômes et fractions rationnelles.
Semestre 2 : analyse asymptotique ; espaces vectoriels et applications linéaires (dont sous-espaces affines) ;
matrices (changements de bases, équivalence, similitude) ; groupe symétrique et déterminants ; intégration ;
dénombrement ; probabilités (univers fini, espérance, variance) ; espaces préhilbertiens réels ; procédés
sommatoires discrets (séries numériques, familles sommables) ; fonctions de deux variables.

**PCSI.** Semestre 1 : raisonnement et vocabulaire ensembliste ; compléments de calcul algébrique et de
trigonométrie ; nombres complexes ; techniques fondamentales de calcul différentiel et intégral ; nombres réels et
suites numériques ; fonctions d'une variable réelle : limites et continuité, dérivabilité ; calcul matriciel et
systèmes linéaires ; polynômes. Semestre 2 : analyse asymptotique ; espaces vectoriels et applications linéaires ;
matrices et déterminants ; intégration ; dénombrement ; probabilités ; espaces préhilbertiens réels ; séries
numériques ; fonctions de deux variables.

**PTSI.** Semestre 1 : raisonnement et vocabulaire ensembliste ; compléments de calcul algébrique et de
trigonométrie ; nombres complexes ; techniques fondamentales de calcul différentiel et intégral ; nombres réels et
suites numériques ; fonctions d'une variable réelle : limites et continuité, dérivabilité ; calcul matriciel et
systèmes linéaires. Semestre 2 : analyse asymptotique ; géométrie du plan et de l'espace ; polynômes ; espaces
vectoriels et applications linéaires ; matrices et déterminants ; intégration ; dénombrement ; probabilités ;
séries numériques ; fonctions de deux variables.

Écarts utiles : arithmétique, structures algébriques, convexité et fractions rationnelles sont propres à
MPSI/MP2I ; PTSI n'a pas d'espaces préhilbertiens en 1re année (ils sont en PT) mais a la géométrie du plan et de
l'espace ; familles sommables en 1re année seulement en MPSI/MP2I.

## Seconde année

**MP, MPI.** Structures algébriques usuelles ; réduction des endomorphismes et des matrices carrées ;
endomorphismes d'un espace euclidien ; topologie des espaces vectoriels normés ; séries numériques et
vectorielles ; suites et séries de fonctions, séries entières ; fonctions vectorielles ; intégration sur un
intervalle quelconque (dont intégrales à paramètre) ; variables aléatoires discrètes (familles sommables) ;
équations différentielles linéaires (dont systèmes) ; calcul différentiel et optimisation.

**PC.** Algèbre linéaire (compléments, réduction) ; endomorphismes des espaces euclidiens ; espaces vectoriels
normés ; suites et séries de fonctions (compléments sur les séries numériques, séries entières) ; intégration sur
un intervalle quelconque (dont intégrales à paramètre) ; variables aléatoires discrètes (ensembles dénombrables,
familles sommables) ; calcul différentiel (fonctions vectorielles, fonctions de plusieurs variables). Pas de
chapitre d'équations différentielles.

**PSI.** Algèbre linéaire (compléments, réduction) ; espaces préhilbertiens réels, espaces euclidiens ; espaces
vectoriels normés ; suites et séries de fonctions (compléments sur les séries numériques, séries entières) ;
intégration sur un intervalle quelconque (dont intégrales à paramètre) ; variables aléatoires discrètes
(ensembles dénombrables, familles sommables) ; calcul différentiel (équations différentielles linéaires scalaires,
d'ordre 2 surtout, et exemples de systèmes à coefficients constants ; fonctions vectorielles ; fonctions de
plusieurs variables).

**PT.** Algèbre linéaire (compléments, déterminants, réduction) ; espaces préhilbertiens et euclidiens (théorème
spectral vu matriciellement) ; fonctions vectorielles d'une variable réelle et courbes paramétrées ; séries
numériques ; séries entières ; intégration sur un intervalle quelconque ; variables aléatoires discrètes ;
équations différentielles et calcul différentiel (équations linéaires scalaires d'ordre 2, fonctions de deux ou
trois variables) ; courbes et surfaces (courbes implicites du plan, surfaces). Ni topologie des espaces normés, ni
familles sommables, ni intégrales à paramètre.
