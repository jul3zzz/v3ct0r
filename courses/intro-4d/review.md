# Relecture · Intro Dimensions

- Sommets : carré $2^2 = 4$, cube $2^3 = 8$, tesseract $2^4 = 16$.
- « on n'en voit que l'ombre » : la vue 02.01 montre une projection (perspective ou stéréographique) dans $\mathbb{R}^3$, puis à l'écran.
- « tranche par tranche » : la vue 02.02 coupe le polytope par les hyperplans $w = c$.
- Fibration de Hopf : $S^3$ est réunion disjointe de grands cercles (les fibres), deux fibres distinctes sont enlacées une fois. « remplit l'espace » : après projection stéréographique, les fibres remplissent $\mathbb{R}^3$ (une fibre devient une droite, cercle passant par l'infini).
- Bouteille de Klein : surface fermée non orientable, d'où « ni intérieur ni extérieur ». Elle ne se plonge pas dans $\mathbb{R}^3$ : la vue montre une immersion, avec auto-intersection.
