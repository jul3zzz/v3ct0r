# Groupes, anneaux et ℤ/nℤ (fiche) — points à faire vérifier

Relecture humaine demandée avant diffusion. Programme suivi : « Structures algébriques usuelles » de MP-MPI (BO 2021, 2e année) : compléments sur les groupes, sur les anneaux, idéaux de $\mathbb{Z}$, anneaux $\mathbb{Z}/n\mathbb{Z}$, anneaux $\mathbb{K}[X]$, algèbres. Section absente de PC, PSI, PT (aucune occurrence d'« idéal » ni de « chinois »).

## Choix de présentation
- « L'ordre d'un élément d'un groupe fini divise le cardinal » : démonstration donnée dans le cas commutatif (« La démonstration n'est exigible que pour G commutatif », à confirmer sur le texte, la mise en colonnes du PDF rendant le rattachement de ce commentaire ambigu).
- Le programme parle de « théorème chinois » ; titre aligné.
- Divisibilité dans un anneau commutatif intègre, irréductibles de $\mathbb{K}[X]$ via les idéaux : non détaillés (renvoi au cours Polynômes).
- Le polynôme minimal est cité comme générateur de l'idéal annulateur (cours Réduction).

## Exercices

- **m1** : $x \equiv 17\ [35]$ ($15 \equiv 1\ [7]$, $-14 \equiv 1\ [5]$).
- **c1** : RSA avec $n = 55$, $e = 3$, $d = 27$ ; $2^{81} \equiv 2\ [55]$.
