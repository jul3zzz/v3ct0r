# Dénombrement (fiche) — points à faire vérifier

Relecture humaine demandée avant diffusion. Programme suivi : « Dénombrement » (2e semestre) de MPSI-MP2I, PCSI et PTSI (BO 2021) : « toute formalisation excessive est exclue », les propriétés les plus intuitives sont admises, la formule du crible est hors programme, l'usage de bijections n'est pas un attendu.

## Choix de présentation
- Format **fiche** ; cardinal défini par une bijection avec $\{1, \ldots, n\}$, unicité admise (tout fondement théorique hors programme).
- Le vocabulaire « arrangement » est mentionné (il n'est pas dans le programme, qui dit « $p$-listes d'éléments distincts »).
- Le crible n'apparaît que comme contrôle numérique dans l'exercice c1, signalé hors programme.

## Exemples et exercices à relire
- Podiums : $10 \times 9 \times 8 = 720$. Anagrammes d'ANANAS : $\binom63\binom32 = 60 = \frac{6!}{3!\,2!}$. OK.
- **s1** : $\binom42\binom{28}{3} = 6 \times 3276 = 19656$ ; $\binom{32}{5} = 201376$.
- **m1** : $\frac{11!}{4!\,4!\,2!} = 34650$.
- **c1** : surjections de $n + 1$ éléments sur $n$ : $\binom{n+1}{2}n!$ ; $n = 2$ : $6$ ; $n = 3$ : $36 = 3^4 - 3\cdot 2^4 + 3$.
